3D Reconstruction of Coronary Angiograms

Lead Developer/Co-Designer · Python, Google Colab, Unity, C#

3D Reconstruction of Coronary Angiograms was an application tied to the EPSCoR DART initiative, and was the stepping stone for a later project. The goal was to bring a collection of 2-dimensional medical data into virtual reality, allowing users to navigate complex structures in a more natural way.

Contribution: As co-designer and lead developer, I was involved in this project from its earliest concepts through final delivery, working closely with Dr. Aryabrata Basu. I started by researching and prototyping a pipeline in Google Colab that converted coronary angiogram data into 3D models, ensuring scans were as accurately portrayed in 3d as possible. Once that approach proved viable, I designed and built an interactive virtual reality Unity application that lets users explore the resulting 3D data, including moving, rotating, and filtering out noisy parts of the data.

Topography Collaboration

Maintainer/Developer · C#, Unity

Originally built as a collboration between Dr. Krista Lewis and the EAC as a way to view a large LIDAR scan of a UNESCO World Heritage archaeological site in Oman, Topography Collaboration became a test-bed for multi-user, multi-control-scheme XR experiences. Users are able to connect to a central server with a variety of different XR capable devices, each user leveraging the unique abilities of their device to view and interact with the world.

Contribution: I joined late in the development cycle of Topography Collaboration and for many years worked as a maintainer. My main responsibilities during this time included updating the Unity version of the application periodically, ensuring the devices used to demonstrate the application were prepared, and demonstrating the application for potential clients and curious students. Later in my tenure at the Emerging Analytics Center, I was asked to transition the back-end networking solution from Photon Unity Networking, to Mirror Networking.

Unity Networking Template

Developer · C#, Unity

Topography Collaboration recieved much interest from prospective clients, but lacked the abstraction to be easily integrated as a core feature of new projects. The Networking Template project was an effort to package the core features of Topography Collaboration into a drag-and-drop solution for future projects. It also included the ability to import 3D objects from a remote server to be displayed within the application.

Contribution: Using the experience gained from transitioning Topography Collaboration to Mirror Networking, I developed the core of the template, focusing on generalized player models pilotable through any control scheme. I then integrated the remote 3D object import code with the template. Much of the development time was spent fixing bugs related to concurrency between the 3D objects imported into a scene.
